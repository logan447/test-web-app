## Data Completeness Levels

### 100% Complete Profiles
- All required fields filled
- Photos uploaded
- Detailed descriptions
- Contact info complete

### 70-90% Complete Profiles
- Missing some optional fields
- Shows "Complete your profile" prompts
- Used for testing profile completion widgets

### 40-60% Complete Profiles
- Minimal information
- Good for testing onboarding flows
- Shows significant completion prompts

---

## Key Demo Flows to Support

1. **Family Onboarding** → Browse → Save → Contact → Tour → Placement
2. **Provider Onboarding** → Complete Profile → View Leads → Connect → Respond
3. **Caregiver Job Search** → Browse Organizations → Apply → Interview → Hire
4. **Organization Hiring** → Browse Caregivers → Reach Out → Interview → Hire
5. **Dual-Mode Switching** → Family Mode → Provider Mode → Back

---

## Implementation Notes

- All timestamps should be realistic (recent activity within last 30 days)
- Messages should have natural conversation flow
- Tour/interview dates should be in the future
- Reviews should reference specific positive experiences
- Budget ranges should be realistic for California market
